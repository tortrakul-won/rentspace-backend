# Fonts for PDF Generation

Place TH Sarabun New font files here before running Gotenberg:

- `THSarabunNew.ttf`
- `THSarabunNew Bold.ttf`

Download from: https://www.f0nt.com/release/th-sarabun-new/ or the Thai SIPA font repository.

These files are gitignored (font licensing). Each developer must download separately.
